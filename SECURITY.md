# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting for this repository when available. If it is not available, contact the maintainers privately through the repository's verified GitHub contact channel and include the affected component, impact, reproduction steps, and a safe contact method.

Do not include real private keys, credentials, or user data in a report.

## Scope

This project is early-stage. Reports involving payment authorization, key handling, transaction verification, provider integrations, dependency vulnerabilities, or documentation that could cause unsafe use are welcome.

Feyo does not currently claim to execute live payments or Nigerian bank payouts from this repository.
