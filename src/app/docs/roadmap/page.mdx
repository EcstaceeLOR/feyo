# Roadmap

Feyo is deliberately transparent about what exists today and what still needs engineering.

## Implemented

- Next.js application foundation.
- MDX documentation routes and responsive navigation.
- Open-source contribution, security, and community policy files.
- CI checks for linting, type checking, and production builds.

## Work in progress

- Refining the product model for permission-based payment execution.
- Defining the developer and agent-facing contracts.
- Researching Stellar transaction and verification boundaries.

## Planned

- Human-facing payment application flows.
- Tested developer API for payment intents and status queries.
- Permissioned MCP tools for AI agents.
- Verifiable Stellar transaction lifecycle support.
- USDC-to-Nigerian-bank payouts through regulated providers.

Dates and milestones will be added when they are backed by an implementation plan. Until then, the status labels above are the source of truth.
